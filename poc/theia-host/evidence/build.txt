A prior session in this same contract hit a permission refusal on every npm/yarn
invocation before any of the above and stopped at BLOCKED (commit f3529f3f). That
refusal did not recur in this session; the install and build above are the first
successful run.

Cause found and fixed in this session, not part of the original theia-ide template
defaults: @theia/core 1.75.0 declares react/react-dom ^19.0.0 as peer dependencies
and its own compiled browser code requires the bare "react", "react-dom" and
"react/jsx-runtime" specifiers directly (not only through @theia/core/shared/react).
The first build attempt failed with 38 esbuild "Could not resolve react..." errors
because neither browser-app nor the extension declared react/react-dom as real
dependencies. Fix: added "react": "^19.0.0" and "react-dom": "^19.0.0" to
browser-app's dependencies and "@types/react"/"@types/react-dom": "^19.0.0" to the
extension's devDependencies, then reinstalled. The original failing log was
overwritten by the successful rebuild; the error text is reproduced in this
session's transcript.
